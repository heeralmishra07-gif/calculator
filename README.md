# Python Tkinter Calculator

A desktop calculator application built with Python using **Tkinter** for the user interface and **pytest** for unit testing.

## Features
- Standard arithmetic operations: Addition, Subtraction, Multiplication, Division
- Clean desktop GUI built with Tkinter
- Input sanitization and error handling
- Automated test suite using `pytest` and GitHub Actions CI

## Running the App

```bash
python main.py # calculator
